# Sales-Dashboard
This repository contains an interactive dashboard designed to monitor and analyze core business performance metrics for an e-commerce platform. It provides a comprehensive view of sales trends, operational efficiency, and customer satisfaction to drive data-informed decision-making.

Key Performance Indicators (KPIs)

    Total Revenue: Tracks overall financial performance and gross sales.   
    image_c9fca6.png

    Operational Efficiency: Monitors the Average Delivery Time in days to assess supply chain speed.   
    image_c9fca6.png

    Volume Metrics: Displays Total Orders and Total Customers to gauge platform growth and retention.   
    image_c9fca6.png

Dashboard Features & Visualizations

    Time-Series Analysis: A line chart detailing "Sales per Months/Quarter" to identify seasonal trends and revenue peaks.   
    image_c9fca6.png

    Geospatial Breakdown: A horizontal bar chart ranking "Sales Per State" (e.g., UP, Rajasthan, Haryana) to highlight top-performing regions.   
    image_c9fca6.png

    Order Logistics: A donut chart breaking down "Order Status" distributions (Delivered, Cancelled, Returned, Processing, Shipped).   
    image_c9fca6.png

    Transaction Preferences: A column chart comparing "Revenue by Payment Method" (UPI, COD, Debit Card, Credit Card).   
    image_c9fca6.png

    Customer Satisfaction: A donut chart categorizing customer "Ratings" into Positive, Neutral, and Negative segments.   
    image_c9fca6.png

    Interactive Filtering: Global slicers allowing users to filter data by specific Date ranges and States.   
    image_c9fca6.png
